# Quiz application – Interactive Quiz Website

Quiz Time is a dynamic and responsive quiz application developed using HTML, CSS, Bootstrap, and JavaScript. It allows users to explore quiz categories, answer multiple-choice questions, track their progress, and view their final results.

## Project Flow

1. **Landing Page** – Created an attractive welcome page with a Start button to begin the quiz journey.
2. **Category Selection** – Dynamically displayed quiz categories using JavaScript and `quizData`.
3. **Quiz Information Page** – Added category details, quiz instructions, total questions, and a Start Quiz button.
4. **Quiz Page** – Displayed questions and multiple-choice options dynamically based on the selected category.
5. **Question Navigation** – Implemented Previous and Next buttons to move between questions.
6. **Answer Selection** – Added interactive option selection and stored selected answers.
7. **Timer & Progress Bar** – Implemented a countdown timer and progress bar to track quiz time and question progress.
8. **Result Page** – Calculated correct answers, wrong answers, attempts, and final score.
9. **Answer Review** – Added a review section to check submitted answers.
10. **Restart & Exit** – Provided options to restart the quiz or return to the category section.

## Features

- Dynamic quiz categories and questions
- Array of objects with nested data structures
- JavaScript DOM manipulation
- Event handling and event delegation
- URL parameters to pass the selected category
- Timer and progress tracking
- Score calculation and result analysis
- Responsive user interface using Bootstrap
- Interactive buttons and selected-answer styling
