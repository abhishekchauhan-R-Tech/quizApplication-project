# Quiz Time – Interactive Quiz Website

Quiz Time is a JavaScript-based quiz application that allows users to choose a quiz category, answer multiple-choice questions, and view their results.

I developed this project as part of my JavaScript learning journey to practice DOM manipulation, event handling, arrays, objects, and dynamic content rendering.

## Project Overview

The website provides a simple quiz experience, starting from category selection and ending with the result and answer review.

## Website Flow

1. **Landing Page** – Users start the quiz by clicking the Enter button.
2. **Category Selection** – Available quiz categories are displayed dynamically from the quiz data.
3. **Quiz Information** – Users can view the selected category's details and quiz instructions.
4. **Start Quiz** – The selected category is passed to the quiz page using a URL parameter.
5. **Answer Questions** – Questions and options are rendered dynamically using JavaScript.
6. **Question Navigation** – Users can move between questions using Previous and Next buttons.
7. **Timer & Progress** – A countdown timer and progress bar help users track their quiz progress.
8. **Result Page** – The application calculates and displays the user's score, correct answers, wrong answers, and attempts.
9. **Answer Review** – Users can review the questions they answered.
10. **Restart & Exit** – Users can restart the quiz or return to the category section.

## Features

- Dynamic quiz categories and questions
- Multiple-choice questions
- Previous and Next question navigation
- Countdown timer
- Question progress bar
- Score and result calculation
- Answer review section
- Restart quiz option
- Responsive layout
